ARCHON v0.1 — GUIA PARA ANDROID

Esta versão tem identidade visual, chat local e comandos básicos (hora, data, piada, ajuda e status). Não é ainda uma IA geral: não tem voz, memória avançada, automação do celular nem conexão a um modelo externo. As mensagens não saem do navegador.

PUBLICAR GRATUITAMENTE:
1. Extraia o ZIP no Android.
2. Crie uma conta no GitHub e um repositório público chamado archon.
3. No navegador, ative "Versão para computador".
4. Envie TODOS os arquivos desta pasta para a raiz do repositório.
5. Abra Settings > Pages.
6. Em Build and deployment, escolha Deploy from a branch, branch main e pasta /(root), depois Save.
7. Aguarde o endereço do GitHub Pages e abra-o no Chrome Android.
8. No Chrome, menu ⋮ > Adicionar à tela inicial ou Instalar app.

TESTES: "Que horas são?", "Qual é a data?", "Ajuda", "Me conte uma piada", "Qual é seu nome?"

SEGURANÇA: não coloque senhas ou chaves de API nos arquivos publicados. Próximas versões adicionarão voz, memória configurável e conexão segura com IA.
